truncate() returns text longer than the requested limit

We use `truncate` to make titles fit a fixed-width column. Long titles now overflow the column by one character.

Example:

    >>> from toolkit.strings import truncate
    >>> truncate("The quick brown fox", 10)
    'The quic...'

That result is 11 characters long. I asked for at most 10, so I expected `'The qui...'`.

Strings that are already short enough come back unchanged, which is correct.
