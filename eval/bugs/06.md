Stock added to one Inventory shows up in other inventories

We keep one `Inventory` object per warehouse. Stock added to one warehouse is appearing in warehouses that were created empty.

Example:

    >>> from toolkit.inventory import Inventory
    >>> north = Inventory()
    >>> north.add("washer", 4)
    >>> south = Inventory()
    >>> south.quantity("washer")
    4

`south` was just created and nothing was added to it, so I expected 0. Each inventory should have its own independent stock. Related: when I build an inventory from an existing dictionary, later changes to the inventory also change my dictionary, which I did not expect either.
