parse_config crashes on config files that contain comments

Loading our settings file fails as soon as it reaches a comment line.

Example:

    >>> from toolkit.parser import parse_config
    >>> parse_config("# settings\nname = demo\n")
    Traceback (most recent call last):
      ...
    ValueError: missing '=' in line: '# settings'

The documentation says comment lines are ignored, and `#` comments are what all our config files use. We call `parse_config` with the text only and no other arguments. I expected `{'name': 'demo'}`.
