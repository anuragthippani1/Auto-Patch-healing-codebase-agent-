scale_to_unit raises ValueError for perfectly normal ranges

Normalising sensor readings stopped working. Every call fails, even with a valid range.

Example:

    >>> from toolkit.mathutils import scale_to_unit
    >>> scale_to_unit(5, 0, 10)
    Traceback (most recent call last):
      ...
    ValueError: low must not be greater than high

The range 0 to 10 is the right way round, so this should return 0.5. Calling `clamp(5, 0, 10)` directly works fine.
