Cart subtotal is wrong when a line has more than one unit

Order totals are coming out too low for carts where a customer buys several of the same item.

Example:

    >>> from toolkit.cart import Cart
    >>> cart = Cart()
    >>> cart.add("pen", 2.50, 4)
    >>> cart.add("book", 12.00)
    >>> cart.subtotal()
    19.5

Four pens at 2.50 plus one book at 12.00 should be 22.00. The number of items in the cart is reported correctly, only the money amount is off.
