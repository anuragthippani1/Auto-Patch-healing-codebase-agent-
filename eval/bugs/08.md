Durations of an hour or more are formatted inconsistently

The job dashboard shows run times such as `1h 2m 03s`. The minutes should be two digits so the column lines up.

Example:

    >>> from toolkit.dates import format_duration
    >>> format_duration(3723)
    '1h 2m 03s'

The documented format is `'1h 02m 03s'`. Durations under an hour, for example `format_duration(125)` giving `'2m 05s'`, look right.
