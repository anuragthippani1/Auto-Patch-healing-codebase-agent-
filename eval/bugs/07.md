balanced_brackets crashes when a closing bracket has no opener

Validating user-entered formulas crashes for some invalid inputs. It should just report that they are not balanced.

Example:

    >>> from toolkit.stack import balanced_brackets
    >>> balanced_brackets(")(")
    Traceback (most recent call last):
      ...
    IndexError: pop from empty stack

Expected `False`. The same crash happens for `"())"`. Inputs such as `"(]"` and `"(("` correctly return `False`.
