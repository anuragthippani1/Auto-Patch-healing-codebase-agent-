Reorder report misses items that are exactly at the threshold

Our reorder job calls `Inventory.low_stock()` every night. Items whose quantity equals the threshold are not being reported, so we run out before reordering.

Example:

    >>> from toolkit.inventory import Inventory
    >>> inventory = Inventory({"bolt": 5, "nut": 2, "gear": 9})
    >>> inventory.low_stock(threshold=5)
    ['nut']

The documentation says items "at or below" the threshold are returned, so I expected `['bolt', 'nut']`.
