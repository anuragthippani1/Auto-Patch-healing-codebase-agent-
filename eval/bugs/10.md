Pager shows too few page links on the first and last pages

The pager under our result lists is meant to always show five page links. On pages in the middle it does, but near either end of the list it shows fewer.

Example:

    >>> from toolkit.pagination import page_window
    >>> page_window(5, 10)
    [3, 4, 5, 6, 7]
    >>> page_window(1, 10)
    [1, 2, 3]
    >>> page_window(10, 10)
    [8, 9, 10]

I expected `[1, 2, 3, 4, 5]` for the first page and `[6, 7, 8, 9, 10]` for the last one: the window should slide to stay inside the valid pages and keep its size, as the documentation describes.
